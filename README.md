# 🧠 AI-Based Deepfake Detection

This project detects AI-generated deepfake images and videos using
**EfficientNet-B0** and deep learning.

## 🔍 Features
- Image Deepfake Detection
- Video Deepfake Detection
- Confidence Score
- Optimized Inference
- Deployed on Hugging Face Spaces

## 🧠 Model
- EfficientNet-B0
- Trained on Deepfake image datasets
- Softmax-based classification

## 🛠 Tech Stack
- Python
- PyTorch
- EfficientNet
- OpenCV
- Gradio
